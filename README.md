# 放課後、二人だけ。（仮）

> 誰もいなくなった夕暮れの学校から、追跡者に見つからないように校門まで脱出する。

Unity で制作中の、**一人称視点の3Dホラー脱出ゲーム**です。
現在は **プロトタイプ（第1段階）** で、オープニングからエンディングまで通して遊べます。
見た目は仮の箱で作っていて、音もプログラムで合成した仮のものです。

---

## ストーリー

主人公の **高橋 蓮** は高校2年生。
友人の佐藤・山本と一緒に、クラスメイトの **相沢 悠** へのいじめに加担していた。
自分から始めたわけではない。ただ、周りに合わせて笑っていた。止めようともしなかった。

ある日の放課後。チャイムが鳴り、ほんの一瞬窓の外に目を向けると、
さっきまで話していた友人たちが消えていた。

夕日に照らされた校庭の真ん中に、一人の生徒が立っている。
学校に来なくなったはずの、相沢だった。

誰もいない学校を探索し、鍵や手掛かりを集めながら、相沢から逃げて校門を目指す。

## このゲームで目指していること

化け物がずっと追ってくる怖さではなく、
**「誰もいない学校のどこかに相沢がいる怖さ」** を中心にしています。

- 相沢は頻繁には出てこない。足音や物音だけが聞こえる時間を長くする
- 遠くに一瞬だけ見える、さっきまで誰もいなかった場所に立っている
- プレイヤーに **「今どこにいる？」** と思わせ続ける
- ストーリーは長いムービーではなく、手紙・黒板・写真・スマートフォンなどの断片で伝える
- 直接的・残酷な描写はしない

## 主な仕組み

### 相沢（追跡者）
| 状態 | 内容 |
|---|---|
| 徘徊 | 校舎の中を歩き回る。階段を使って別の階にも行く |
| 警戒 | 足音や扉の音を聞くと、確かめに来る |
| 発見 | **目が合う**（16m以内）か、4m以内で見られると見つかる |
| 追跡 | 走って追いかけてくる。角を曲がって3秒視線を切れば見失う |
| 探索 | 見失った場所の周りを探し回る |

### 隠れる
各教室と廊下に **掃除用具ロッカー** があります。
中からは扉の上のすき間から外をのぞけます。
ただし、隠れるところを見られていたら引きずり出されます。

### スタミナ
ダッシュは約4秒。使い切ると息切れして、歩くのも遅くなります。
いつ走るかの判断が大切です。

### アイテム
拾ったアイテムは目の前でマウスで回して見られます。手紙はそこで読めます。
拾ったアイテムは右手に持って画面に映ります。

## プロトタイプの流れ

1. **3階 2年3組**：オープニング。閉じ込められた教室で、相沢の机から鍵を見つける
2. **1階 職員室**：担任の机から、渡り廊下の鍵を見つける
3. **体育館 → 体育倉庫**：校門の鍵を見つける
4. **校庭**：体育館から相沢が現れ、最後の追跡
5. **校門**：解錠に3秒。外に出るとエンディング

## 開き方

1. [Unity Hub](https://unity.com/download) で **Unity 6000.6.3f1** をインストールする
2. このリポジトリをダウンロードして、Unity Hub の「追加」でフォルダを開く
3. Unity のメニュー **「放課後」→「校舎プロトタイプ（オープニング）を作成」** を押す
   （シーンは自動で組み立てられます）
4. ▶（再生）を押す

※ 動きだけを確かめたいときは「放課後」→「プレイヤーのテストシーンを作成」を使います。
