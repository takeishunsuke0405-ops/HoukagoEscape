# 設計書 Ver1（マップ・進行・相沢・手紙）

要件定義書Ver1をもとに、実際に作るための具体的な内容をまとめる。
数値はすべて**仮の値**。Unityで遊びながら調整する。

# 0. 決定事項

- 舞台は**高校のまま**。校庭の遊具や図工室は、少し不思議な学校の雰囲気として残す
- 操作に**しゃがみ（Ctrl）**を追加する
- 「気合い」の仕組みは入れない
- 相沢には**お互いに見たとき**に見つかる
- 息切れ中（ゲージが赤いとき）は歩きより遅くなる（1.5 m/s）
- 歩く・走る・しゃがむときに、画面下の両手が動く
- アイテムを拾うと目の前に出てきて、マウスで回してよく見られる（手紙はそこで読める）
- 拾ったアイテムは右手に持って画面に映る

### 追加した操作
| 操作 | キー |
|---|---|
| しゃがむ | Ctrl（押している間） |
| 持っているアイテムをよく見る | 右クリック |
| 持ち替え | マウスホイール ／ 1〜9 |
| アイテムをしまう（手ぶら） | Q |
| よく見る画面を閉じる | E ／ 右クリック |

# 4. 相沢の仕様

## 4-1. 見つかる条件

### 視線（お互いに見たら見つかる）
- **相沢の視界にプレイヤーが入り、プレイヤーも相沢を見ている**（目が合う）と見つかる
- 間に壁などの遮るものがあるときは見つからない
- 見つかる距離は**約16m**（教室2つ分。教室1つを約8mとした場合）
- 相沢の視野の角度は**前方110°**。プレイヤー側は、相沢が画面の中央付近に映っていれば「見ている」とする
- プレイヤーが相沢を見ていなくても、相沢の視界に入った場合は**警戒（怪しむ）**になる
- ただし**4m以内**で相沢の視界に入った場合は、目が合っていなくても見つかる（見なければ安全、という抜け道を防ぐため）

→ 「振り返ったら目が合ってしまった」という怖さを演出できる。

### 物音
プレイヤーが音を立てると、その場所を**怪しまれる**。

| 行動 | 音が届く範囲 |
|---|---|
| しゃがみ歩き（Ctrl） | 0.5m |
| 歩く | 3m |
| ダッシュ | 12m |
| ジャンプの着地 | 6m |
| ドアを開け閉めする | 8m |
| 物を落とす・ぶつかる | 10m |
| 隠れている | 0m |

## 4-2. 状態

```
徘徊 ──(物音)──→ 警戒（怪しむ）──(視線が通る)──→ 発見 → 追跡
 ↑                   │                                │
 │               (見つからない)                    (見失う)
 │                   ↓                                ↓
 └──────────────── 徘徊に戻る ←──────────────────── 探索
```

| 状態 | 移動の速さ | 内容 |
|---|---|---|
| 徘徊 | 1.4 m/s | 決められたルートを歩く。どこにいるか分からない時間を長くする |
| 警戒（怪しむ） | 2.0 m/s | 音がした場所へ向かい、8秒ほど見回す。**この間にゆっくり歩くか隠れれば回避できる** |
| 発見 | 停止 | 1秒立ち止まって、こちらを見る（逃げ始める猶予） |
| 追跡 | 4.6 m/s | 走って追いかけてくる |
| 探索 | 2.0 m/s | 見失った場所の周辺を15秒探す |

## 4-3. 逃げ方

| プレイヤーの状態 | 速さ |
|---|---|
| しゃがみ歩き（Ctrl） | 1.5 m/s（足音がほぼ出ない。机や教卓の陰に隠れやすい） |
| 歩き | 3.0 m/s |
| 息切れ中の歩き | 1.5 m/s（スタミナ切れから25%まで回復するあいだ。ゲージが赤い） |
| ダッシュ | 5.5 m/s（相沢より少し速い） |

- **ダッシュで少し耐えられる**：ダッシュ中は相沢より速いので、4秒で約3.6m引き離せる
- **角を曲がる、ドアを抜けるなどで視線を3秒切れば見失わせられる** → 探索状態になる
- **近い状態では逃げられない**：距離が**4m以内**になると相沢が掴みかかる（6.0 m/s）ので、ダッシュしても捕まる
- 捕まる判定は1m以内
- 「気合い」のような特別な逃げ方は入れない。ダッシュと視線を切ることだけで逃げる

## 4-4. 隠れる
- 隠れている間は見つからない
- ただし**隠れるところを見られていた場合**は、相沢に引きずり出される（ゲームオーバー）
- 相沢が近くにいるときは、ランダムでロッカーを「ドン」と叩く（要件定義書どおり）

# 7. プロトタイプ（第1段階）で作る範囲

要件定義書の第1段階を、このマップに合わせて置き換える。

- 3階：全部の部屋に入れる（2年3組から開始）
- 1階：廊下 ＋ 職員室（1部屋だけ）
- 東西の階段（1〜4階）、渡り廊下 → 体育館（体育倉庫・ステージ）→ 校庭 → 校門
- 相沢：徘徊・警戒・発見・追跡・探索・ゲームオーバー、ロッカーに隠れる

### プロトタイプの鍵の流れ（短い版）
| # | 場所 | 手に入るもの |
|---|---|---|
| 1 | 3階 2年3組・相沢の机 | 2年3組の鍵 |
| 2 | 1階 職員室・担任の机の引き出し | 渡り廊下の鍵（上に手紙④） |
| 3 | 1階 東の突き当たり → 渡り廊下 → 体育館 | （ステージに手紙⑧） |
| 4 | 体育倉庫・ボールかご | 校門の鍵（マットの上に手紙⑨） |
| 5 | 体育館の南の出口から校庭へ | **クライマックス**：体育館から相沢が現れて最後の追跡（速さ 3.8 m/s） |
| 6 | 校門 | 解錠に3秒 → 外に出るとエンディング |
