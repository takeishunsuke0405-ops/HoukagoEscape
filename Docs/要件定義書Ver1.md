# 3Dホラー脱出ゲーム 要件定義書

## 1. ゲーム概要

### 仮タイトル
**「放課後、二人だけ。」**

### ジャンル
一人称視点3Dホラー脱出ゲーム

### コンセプト
「誰もいなくなった夕暮れの学校から、追跡者に見つからないように校門まで脱出する。」

主人公は過去にクラスメイトへのいじめに加担していた高校生である。

ある日の放課後、主人公が友人たちと教室で話していると、突然チャイムが鳴る。

ほんの一瞬、窓の外へ目を向ける。

再び教室を見ると、そこにいたはずの友人もクラスメイトも全員消えている。

廊下にも人はいない。

しかし、遠くから机を引きずる音や足音だけが聞こえてくる。

主人公が教室の窓から校庭を見ると、一人の生徒がこちらを見上げている。

かつて主人公たちがいじめていたクラスメイト、

**「相沢 悠（あいざわ ゆう）」**

である。

夕日の中、相沢は校庭の中央から無言で主人公を見つめている。

そして主人公がもう一度目を離した瞬間、その姿は消える。

主人公は誰もいない学校を探索し、鍵や手掛かりを集めながら、相沢から逃げて校門を目指す。


# 2. ゲームの目的

プレイヤーの最終目的は、

**「学校から脱出し、校門の外へ出ること」**

である。

ただし、校門は最初から開けることができない。

校内を探索して、

- 教室
- 職員室
- 保健室
- 図書室
- 音楽室
- 体育館
- 校庭

などを巡り、鍵やアイテムを集める。

最終的に「校門の鍵」を入手して脱出する。


# 3. 主人公

### 名前
**高橋 蓮（たかはし れん）**

高校2年生。

友人グループの一員として相沢へのいじめに加担していた。

ただし、主人公を極端な悪人として描くのではなく、

「自分から始めたわけではない」
「周囲に合わせて笑っていた」
「止めようともしなかった」

という立場にする。

ゲームを進めるにつれて、主人公自身が「自分は直接やっていない」という言い訳をしていたことが分かってくる。


# 4. 過去のいじめ

ストーリー説明は短くする。

過去に相沢はクラスで孤立していた。

主人公たちは、

- 相沢の机だけ少し離す
- 上履きを隠す
- 持ち物を勝手に別の場所へ移す
- グループチャットで本人だけ外す
- 相沢が発表すると小さく笑う
- 体育のグループ分けで誰も相沢を選ばない
- 黒板に相沢をからかう言葉を書く

といった行為を繰り返していた。

特に主人公は積極的に暴力を振るっていたわけではない。

しかし、

**「周囲と一緒になって笑っていた」**

ことが後から重要になる。

ある日、相沢の机に

「明日から来なくていい」

という紙が置かれる。

主人公もその場にいたが、何も言わなかった。

翌日から相沢は学校に来なくなる。

ゲーム開始時点では、その後どうなったのか明確には説明しない。


# 5. オープニング

夕方。

教室にはオレンジ色の夕日が差し込んでいる。

主人公は友人2～3人と雑談している。

友人：
「そろそろ帰るか。」

主人公：
「そうだな。」

その瞬間、

**キーンコーンカーンコーン……**

放課後のチャイムが鳴る。

主人公が窓の外を見る。

夕日に照らされた校庭。

誰もいない。

主人公：
「……？」

後ろを振り返る。

さっきまで話していた友人たちが消えている。

机の上には友人のスマートフォンだけが残されている。

主人公：
「おい？」

返事はない。

廊下へ出ても誰もいない。

教師も、生徒もいない。

すると遠くから、

「ガタン……」

という音がする。

主人公は教室へ戻り、窓から校庭を見る。

校庭の中央。

夕日の逆光の中に、人が立っている。

相沢である。

顔はよく見えない。

しかし明らかにこちらを見ている。

主人公：
「……相沢？」

相沢は動かない。

数秒後、校内の照明が一瞬だけ消える。

再び点灯する。

校庭から相沢が消えている。

直後、

校舎のどこかから足音が聞こえる。

ここからプレイヤー操作開始。


# 6. 基本操作

PCキーボード＋マウス操作を基本とする。

| 操作 | キー |
|---|---|
| 前進 | W |
| 後退 | S |
| 左移動 | A |
| 右移動 | D |
| 視点移動 | マウス |
| 調べる・拾う・ドア操作 | E |
| ダッシュ | Shift + W |
| ジャンプ | Space |
| 所持アイテム確認 | Tab |
| メニュー | Esc |

※「Spaceで走る」よりも、一般的なFPS操作に合わせてSpaceをジャンプ、Shiftをダッシュとする。


# 7. 基本ゲームシステム

ゲームの基本ループは、

**探索 → アイテム発見 → 新しい場所を解放 → 追跡 → 謎解き → 校門へ近づく**

とする。

プレイヤーは学校を自由に探索できる。

しかし、一部の場所は施錠されている。

例えば、

「職員室の鍵」

を見つける。

↓

職員室へ入る。

↓

机の引き出しから

「体育館倉庫の鍵」

を入手する。

↓

体育館へ向かう。

というように探索範囲が徐々に広がる。


# 8. アイテム

主なアイテムとして以下を実装する。

### 鍵

- 2年3組教室の鍵
- 職員室の鍵
- 音楽室の鍵
- 体育館倉庫の鍵
- 校門の鍵

### 探索アイテム

- 懐中電灯
- 電池
- 生徒手帳
- スマートフォン
- 教室配置図
- ロッカー番号メモ

### ストーリーアイテム

- 相沢のノート
- 破られたプリント
- クラス写真
- 手紙
- 主人公たちのグループチャット記録


# 9. 手紙システム

学校の各所に相沢が書いたと思われる文章が残されている。

例えば教室で、

「今日も俺の机だけ離れていた。」

体育館で、

「先生が来た瞬間だけ、みんな普通になる。」

階段で、

「高橋は何もしなかった。
でも、ずっと笑っていた。」

などが発見できる。

これによってプレイヤーは探索しながら主人公と相沢の過去を理解していく。


# 10. 追跡者システム

相沢はゲーム中、学校内を徘徊する。

常に追跡するのではなく、

**「どこにいるか分からない時間」**

を多くする。

これによって恐怖感を出す。

### 相沢の状態

#### 状態1：徘徊
校内を歩いている。

#### 状態2：気配
姿は見えない。

しかし、

- 足音
- ドアが閉まる音
- 机が動く音
- 遠くの足音

などが聞こえる。

#### 状態3：発見
相沢が主人公を発見する。

一瞬立ち止まった後、主人公へ走ってくる。

#### 状態4：追跡
主人公を追いかける。

プレイヤーは走って逃げる。

#### 状態5：探索
主人公を見失った場合、その周辺を一定時間探す。


# 11. 隠れるシステム

プレイヤーは、

- ロッカー
- トイレ
- 教卓の下
- 体育倉庫
- 清掃用具入れ

などに隠れることができる。

相沢が近くを通ると足音が大きくなる。

ロッカーに隠れている場合、

「ドン」

と突然ロッカーを叩かれる演出を入れる場合がある。

ただし毎回発生させず、ランダムにする。


# 12. ダッシュシステム

Shift＋Wでダッシュする。

ただし無限に走ることはできない。

スタミナゲージを設定する。

ダッシュすると減少し、歩くことで回復する。

そのため、

「相沢から逃げるためにいつ走るか」

という判断が必要になる。


# 13. 音による恐怖演出

本ゲームではジャンプスケアだけに依存しない。

特に「音」を重視する。

例：

誰もいないはずの上階から、

「ドン……」

と音がする。

廊下を歩いていると後ろから足音が聞こえる。

振り返る。

誰もいない。

再び前を見る。

遠くの廊下に相沢が立っている。

照明が一瞬消える。

再び点灯すると消えている。

# 15. 時間変化

ゲーム開始時は夕方。

進行するにつれて徐々に暗くなる。

### 序盤
オレンジ色の夕日。

比較的明るい。

### 中盤
日没。

校内が暗くなり始める。

### 終盤
完全な夜。

懐中電灯が重要になる。

これによって同じ学校でも時間によって雰囲気を変化させる。


# 16. ストーリーの見せ方

長いムービーは使用しない。

ストーリーは、

- 手紙
- 黒板
- 写真
- スマートフォン
- 教室
- 主人公の短い独り言

によって断片的に伝える。

プレイヤーが探索するほど、

「なぜ相沢が主人公を追っているのか」

が分かる構成とする。


# 17. ゲームオーバー

相沢に捕まると画面が暗転する。

直接的・残酷な描写は必要ない。

暗転直前、

相沢の顔が一瞬だけ画面いっぱいに映る。

その後、

GAME OVER

を表示。

直前のチェックポイントから再開できる。


# 18. クライマックス

すべての謎を解き、主人公は「校門の鍵」を入手する。

校舎から校庭へ出る。

校門までは約100メートル。

その瞬間、校舎から相沢が現れる。

最後の追跡開始。

プレイヤーはスタミナを管理しながら校庭を走る。

校門へ到着。

鍵を使用する。

しかし鍵を開けるまで数秒かかる。

背後から足音が近づく。

鍵が開く。

主人公が校門の外へ飛び出す。

画面暗転。


# 19. エンディング

主人公が目を開ける。

学校には再び生徒たちがいる。

時間も放課後に戻っている。

主人公の友人が言う。

「どうした？」

主人公は窓を見る。

校庭には誰もいない。

しかし主人公の机の上に、

ゲーム中に読んだはずの相沢の手紙が置かれている。

最後に一文だけ表示する。

**「見ていただけでも、同じだった。」**

暗転。

END


# 20. 開発上の優先順位

最初から大規模な学校を完成させない。

### 第1段階：プロトタイプ

まず、

- 教室1つ
- 廊下
- 階段
- 校庭
- 校門
- プレイヤー移動
- ドア
- 鍵
- アイテム取得
- 相沢の簡単な追跡AI
- ゲームオーバー
- 脱出

だけを作る。

これだけで最初から最後まで遊べる状態を作る。

### 第2段階：ゲームシステム

- アイテムリスト
- 複数の鍵
- スタミナ
- 隠れる
- 手紙
- チェックポイント
- 懐中電灯

を追加する。

### 第3段階：学校拡張

- 職員室
- 保健室
- 図書室
- 音楽室
- 理科室
- 体育館
- トイレ

などを追加する。

### 第4段階：ホラー演出

- 足音
- ドア音
- 照明点滅
- ランダムイベント
- 相沢の出現
- BGM
- 環境音

を追加する。

### 第5段階：ストーリー

最後に、

- 手紙
- 写真
- スマートフォン
- 主人公の独り言
- オープニング
- エンディング

を組み込む。


# 21. 最重要方針

このゲームでは、

「化け物がずっと追ってくる怖さ」

ではなく、

**「誰もいない学校のどこかに相沢がいる怖さ」**

を中心にする。

相沢を頻繁に出現させない。

音だけ聞こえる時間や、

遠くに一瞬だけ見える場面、

さっきまで誰もいなかった場所に立っている場面、

などを多くする。

プレイヤーに、

**「今どこにいる？」**

と思わせ続けるゲームを目指す。
